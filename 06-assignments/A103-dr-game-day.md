# A103 · Disaster Recovery Game Day

| Level | Topic | Estimated time | Read first |
|---|---|---|---|
| 🔴 Expert | Backup & DR | 1–2 days | [Module 28 · Backup & Disaster Recovery](../02-modules/28-backup-disaster-recovery.md) |

## Scenario

Run a disaster recovery game day for your platform.

## Your tasks

1. Define RPO/RTO for two services
2. Simulate losing a namespace and then a whole cluster
3. Recover using GitOps, Velero and runbooks
4. Measure actual RPO/RTO
5. Write a blameless report with action items

## Acceptance criteria

- [ ] Measured vs target RPO/RTO compared
- [ ] Gaps found and documented
- [ ] Action items owned and prioritised

<details>
<summary>Hints (try without them first)</summary>

- Time everything; start the clock when the incident is declared

</details>

## Stretch goal

Automate the game day so it can run quarterly.

## Submit

Push your manifests, scripts and a short `NOTES.md` (what you did, what broke, what you learned) to your own repository. Share it on LinkedIn and tag **DevOps Shack** if you'd like feedback.
