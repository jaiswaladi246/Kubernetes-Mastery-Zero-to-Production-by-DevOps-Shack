## How to use the modules

1. Read the module. Type out the YAML rather than copying it.
2. Do the linked lab on a local kind cluster.
3. Attempt the linked assignments without looking at hints first.
4. Test yourself with the [interview questions](../07-interview-questions/README.md) for that topic.

Prefer the deep internals first? Start with [Architecture](../01-architecture/README.md).
