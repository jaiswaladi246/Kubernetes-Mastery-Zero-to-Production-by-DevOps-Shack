# Contributing

Thank you for helping improve **Kubernetes Mastery: Zero to Production**.

## Ground rules

1. Every Markdown file starts with the DevOps Shack header block and ends with the DevOps Shack footer block. Pull requests that remove or alter them fail the automated **branding check** and will not be merged.
2. Every YAML manifest and shell script keeps its first-line DevOps Shack banner comment.
3. `LICENSE`, `NOTICE` and `AUTHORS.md` can only be changed by the maintainers (see `.github/CODEOWNERS`).
4. Contributions are accepted under the repository license (CC BY-NC-SA 4.0) and credited in `AUTHORS.md`.

## Good contributions

- A wrong answer, a typo, a broken link or an outdated API version.
- A manifest that no longer applies on a current Kubernetes version.
- A new scenario you hit in production, written in the same style as the existing banks.

Run `bash tools/check-branding.sh` before opening the pull request.
